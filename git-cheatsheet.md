# Git Command Cheat Sheet

* **git --version**  
  * **Purpose:** Check the installed Git version[cite: 7].

* **git config --global user.name "Your Name"**  
  * **Purpose:** Set your global Git username[cite: 7].

* **git config --global user.email "your@email.com"**  
  * **Purpose:** Set your global Git email address[cite: 7].

* **git config --list**  
  * **Purpose:** Show your current Git configuration information[cite: 7].

* **git clone <repository-url>**  
  * **Purpose:** Download/clone a GitHub repository to your local computer[cite: 7].

* **git status**  
  * **Purpose:** Display the status of your files (tracked, untracked, or modified)[cite: 7].

* **git add .**  
  * **Purpose:** Add all modified or new files to the staging area[cite: 7, 8].

* **git commit -m "Your commit message"**  
  * **Purpose:** Save your staged changes locally with a descriptive message[cite: 7, 8].

* **git push**  
  * **Purpose:** Upload your local commits up to GitHub[cite: 7, 8].

* **git pull**  
  * **Purpose:** Download and merge changes from the remote GitHub repository[cite: 7].

* **git log --oneline**  
  * **Purpose:** Display a compact project history of your commits[cite: 7, 8].

* **git branch <branch-name>**  
  * **Purpose:** Create a new branch[cite: 7].

* **git checkout <branch-name>**  
  * **Purpose:** Switch to another branch[cite: 7].

* **git merge <branch-name>**  
  * **Purpose:** Merge another branch into your current active branch[cite: 7].
